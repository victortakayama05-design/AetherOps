# AetherOps Landing Page

Projeto em Next.js + Tailwind pronto para upload em um repositório do GitHub e deploy na Vercel.

## Como usar
1. Faça upload desta pasta para um repositório GitHub.
2. Importe o repositório na Vercel.
3. A Vercel deve detectar automaticamente que é um projeto Next.js.
4. Clique em Deploy.

## Observação
O formulário atual é visual. Ele ainda não envia dados para nenhum backend.
